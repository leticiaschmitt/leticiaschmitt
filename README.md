## 💡 Sobre mim

Sou formada em **Ciências Contábeis**, possuo **MBA em Customer Experience** e atualmente curso **Análise e Desenvolvimento de Sistemas na FIAP**.

Minha trajetória começou no mercado financeiro, mas foi na tecnologia que encontrei a oportunidade de unir análise, comunicação e resolução de problemas.

Atualmente, atuo como **Analista de Integrações Pleno** no **[Asaas](https://www.asaas.com/)**, trabalhando com **APIs, integrações, documentação técnica, diagnóstico de incidentes e suporte a pessoas desenvolvedoras**.

Também atuo em iniciativas de **Developer Relations**, aproximando tecnologia, produto e comunidade dev. Minha missão é simplificar integrações, traduzir problemas complexos e melhorar a experiência de quem utiliza APIs. 🚀

## 🚀 Projetos em destaque

<details>
  <summary><strong>Easy Finanças ESG API</strong> 💸🌱</summary>

  <br>

API RESTful desenvolvida com **Java e Spring Boot** para gerenciamento financeiro sustentável, com foco em segurança, rastreabilidade e princípios ESG.

O projeto contempla autenticação com JWT, integração com banco Oracle, migrations com Flyway, documentação com Swagger/OpenAPI e conteinerização com Docker.

**Tecnologias:** Java, Spring Boot, Spring Security, JWT, Oracle Database, Flyway, Swagger/OpenAPI, Docker e Docker Compose.

🔗 [Ver projeto](https://github.com/leticiaschmitt/easy-financas-esg-api)

</details>

<details>
  <summary><strong>EcoWater API</strong> 💧</summary>

  <br>

API REST desenvolvida em **ASP.NET Core 8** para monitoramento do consumo de água, identificação de desperdícios e geração de relatórios ambientais.

Possui gestão de sensores, detecção automática de vazamentos, alertas, autenticação JWT, paginação, testes automatizados e documentação com Swagger.

**Tecnologias:** ASP.NET Core 8, C#, Entity Framework Core, SQL Server, JWT, Swagger, xUnit e Docker.

🔗 [Ver projeto](https://github.com/leticiaschmitt/EcoWater-API)

</details>

<details>
  <summary><strong>INOVAGAB</strong> 🚀📱</summary>

  <br>

Aplicativo mobile desenvolvido como projeto acadêmico para a FIAP.

A solução permite o cadastro, gerenciamento e acompanhamento de ideias e projetos de inovação dentro de empresas, promovendo colaboração e engajamento entre equipes e lideranças.

**Tecnologias:** Kotlin, Android Studio, Jetpack Compose, Firebase Authentication, Firebase Firestore, MVVM e Navigation Compose.

🔗 [Ver projeto](https://github.com/leticiaschmitt/inovagab-android)

</details>
